# Menu icons

Phosphor Icons (regular weight), MIT licence, https://phosphoricons.com (package `@phosphor-icons/core` 2.1.1).
Each SVG was rendered to a 96 x 96 white PNG so the app can tint it with the image component's `tintColor`; no icon
package is installed. Source files are not kept here. To add one: take the SVG from the package, replace `currentColor`
with `#ffffff`, and render it the same way.
