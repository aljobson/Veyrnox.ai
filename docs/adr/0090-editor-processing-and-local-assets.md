# ADR-0090 — Editor processing, captions and local assets

Status: implemented in the completion branch with native development verification. Hosted qualification and production activation remain pending.

## Decision

Each browser processing operation has an explicit action, bounded input, progress/cancellation, stale-result protection and a separate editable output. Original sources remain in the project; inserting the result participates in ordinary Undo. Outputs inherit source attribution. Processing stays local and introduces no credit debit or provider job.

Motion processing implements horizontal/vertical stabilization, exposure-flicker correction, measured texture-region tracking/reframe, manual camera pan/zoom and bidirectional optical-flow interpolation. Ordinary operations accept up to 30 seconds at 720p; optical flow accepts up to ten seconds at 480p/60 fps. Stabilization may crop edges. Tracking measures a selected texture region rather than recognizing a semantic subject; manual camera movement is a crop path rather than generative movement. AAC packet passthrough preserves source sound exactly. Unsupported audio codecs are refused before processing rather than silently dropping sound.

Pinned multiclass person segmentation implements solid background replacement, transparent removal, skin smoothing/light adjustment, silhouette glow and largest-person reframing, up to ten seconds at 720p. Opaque outputs are MP4 with source AAC preserved. Transparent output is a silent VP9 WebM overlay and requires a silent source. The editor preserves alpha through its original source decoder, preview and MP4 compositor; an MP4 preview proxy is refused because it would flatten transparency. The isolated Worker/model provenance, bounds and quality evidence are in [ADR-0092](0092-editor-isolated-person-vision-runtime.md).

Local automatic captions recognize the actual audible timeline mix, including mute/solo, gain and source time mapping. The initial bound is 120 seconds. Measured word intervals are required; estimated evenly spaced words do not become automatic recognition. An isolated same-origin URL Worker runs pinned Whisper/ONNX assets, with no audio upload or microphone permission. Cancellation terminates inference, and completed cues are inserted atomically as editable text. [ADR-0091](0091-isolated-local-speech-recognition.md) records the runtime and model contracts.

Caption translation uses the browser's on-device Translator API after a user action. It preserves cue positions and visual styling, removes obsolete source-language word alignment, rejects locked tracks and cancels on edit/account changes. Unsupported or unavailable translation models produce an explicit failure and preserve the original cues. A successful native translation output has not been qualified.

Data-only local catalog packs carry declared attribution/usage, bounded filenames, MIME and SHA-256. Import permits no executable extension code or arbitrary remote fetching. Usage statements do not grant rights to a commercial provider catalog.

Version-3 project documents optionally retain up to 40 explicit folder paths and eight local-font declarations. Folders support four levels, subtree rename/move and empty-folder persistence. Existing media labels remain readable; organization operations preserve media identity and Undo. Custom fonts accept TTF/OTF/WOFF/WOFF2 up to 2 MiB, with source name, SHA-256 and rights metadata. User-selected bytes are checked and loaded through FontFace from an ArrayBuffer. Font files remain local; another browser must relink the same bytes. Export refuses a missing used custom font rather than changing its appearance. A font used by text cannot be removed until that text uses another font.

Migration `0286_editor_folders_and_fonts.sql` adds bounded folder/font validation while retaining legacy document readers, caller-JWT writer ACLs, history and the 32-KiB document ceiling. New validation helpers explicitly revoke API-role execution. Private Library rendering is a separate contract in [ADR-0089](0089-editor-private-library-delivery.md), migration `0285_editor_library_renders.sql`. Native social video retry fencing is [ADR-0093](0093-native-editor-video-destinations.md), migration `0287_tiktok_submission_fence.sql`.

Existing Fal and KIE source/generation contracts remain the provider boundary. Dedicated voiceover and avatar/lip-sync controls use only models returned by the live catalog, normal consent, debit/refund/idempotency, polling and Library recovery. Public prompt limits now match the registry. This work adds no catalog activation, price or voice entitlement; registered KIE speech contracts were absent from the inspected live catalog. [ADR-0094](0094-explicit-generation-source-slots.md) records the bounded owned-source assignments.

## Verification recorded on 11 October 2026

All five motion and all five person operations were driven in the actual editor with positive Reticle processing verdicts and real downloaded outputs. Independent media decoding measured the outputs rather than accepting a completion message alone. Stabilization reduced translational jitter by 97.04% on the selected compressed fixture, while source AAC packets and the decoded 96,000-sample PCM were identical. Other fixture measurements and their limits are recorded in ADR-0092.

The corrected transparent person download retained foreground face alpha 255 and clear-background alpha 0–1 across all 60 pictures. The matching solid-background output retained the selected background colour. The actual editor then exported a four-second, 640×360 H.264 MP4 with 120 pictures, placing the colour cutout over a grayscale source layer. Independent decoding retained the coloured face and grayscale background; a positive Reticle export verdict accompanied the file. These results qualify the bounded tested flow, not arbitrary hair, lighting, occlusion or multi-person footage.

Actual local automatic recognition inserted ten measured words from the audible synthetic speech fixture in the integrated editor. A separate cancellation/restart probe exercised the same pinned runtime. Native caption translation could not create the required browser model; the failure preserved the original cues. Local catalog-pack import and folder creation/move/Undo have positive Reticle verdicts.

An actual Archivo OFL font loaded, was selected for a title and exported to a valid 640×360 H.264 MP4 of 90 pictures/three seconds. Hash/relink, metadata and removal-while-used guards have meaningful unit coverage. The font-removal UI guard was not driven: automatic approval review rejected that potentially destructive test click, so no browser verdict is claimed for it.

A fresh disposable PostgreSQL 17.11 database replayed all 267 canonical migrations, including editor 0285–0287 and the preceding Cinema migrations. The new migrations were replayed twice. Library security/storage, folder/font save/replay/restore, exact-claim submission fencing, default privileges and foreign-key indexes passed; fixtures were rolled back. Focused generation, source assignment, organization, Library and native publishing tests passed. These local database and transport tests do not establish hosted saving or provider acceptance.

## Rollout and remaining qualification

Editor migrations 0285–0287 have been applied to staging only. The exact-head Worker build, generated asset verification, green CI, deployed staging flag readback and actor/permission checks passed. Signed-in staging folder/font saving, reload, missing-font export refusal and same-font relink passed with a real decoded MP4. That journey found a delivery bug: fetching the export's blob URL violated the unchanged page CSP. The fix retains its already-created Blob for direct delivery. Corrected staging delivery, private render inspection/readback/cleanup and a Publish draft handoff that stops before posting remain required. Receipts and evidence are in [the staging qualification record](../editor/COMPLETION-STAGING-2026-10-11.md). `EDITOR_ORGANIZATION_ENABLED`, `EDITOR_LIBRARY_EXPORTS_ENABLED`, `EDITOR_LOCAL_INFERENCE_ENABLED` and `PUBLISH_VIDEO_DESTINATIONS_ENABLED` remain false in production preparation configuration. The native destination flag also remains false in staging until provider qualification. The existing advanced workspace (0269), shared brand/review (0280), cloud saving, project media uploads, paid inference and Cinema gates remain independent. Elapsed time or a latest zero snapshot alone does not prove a clean reconciliation window.

Broader real-footage and low-resource/browser quality qualification remains open, especially rotation/parallax, rapid movement, occlusion, segmentation edges, translation language pairs and larger exports. Lyric-specific recognition/alignment, vocal isolation, semantic/depth relighting, face/body reshaping, generative AI movement, licensed stock/Epidemic Sound/GIPHY agreements and TikTok Ads advertiser/creative contracts remain genuine feature gaps. No local result establishes full CapCut parity or a production release.
