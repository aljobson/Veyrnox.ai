## Phone: what exists
- Hub row `speech` -> `audioTarget()` in `src/lib/audioHub.ts` -> generic `/create/[modelId]` for the cheapest speech model.
- Generic Create (`src/app/(app)/create/[modelId].tsx`): prices from catalog (`estimateCredits`), submits through `createGenerationSubmit` (`src/lib/generationSubmit.ts`: one key per request signature, kept on retry, rotated only on proven-dead refusals), polls via `CreateResult` / `useJobResult`, plays audio with `InlineMedia` (play, seek bar, +/-10 s accessibility actions). `acceptedSettings` only forwards catalog-declared options; the ten speech controls are `hidden` in `/api/catalog`, so the generic form cannot send them.
- Guards already in the client: `/api/v1/generations` is in `CONTENT_POSTS` (`aiConsent.ts`) and `PAID_ACTIONS` (`hardPaywall.ts`), enforced inside `mediaApi.createGeneration`/the API client. The studio must keep using that path; tests prove it with the real guard.

## Server contract (read, not guessed)
`POST /api/v1/generations`, model `minimax-speech-2.6-hd` (fal-ai/minimax/speech-2.6-hd, 6 credits): `inputs.prompt` plus `tts_voice, tts_emotion, tts_speed, tts_volume, tts_pitch, tts_language`. Rules in `lib/speechInputs.js` (`TTS_INPUT_RULES`). A speech key sent to a model without the capability is `400 inputs_key_not_allowed:<key>` before debit.

## Slices
- **A (this PR)**: native studio screen `/speech`: script (500), voice picker (gender filter, full name + tone), language, emotion, speed, volume, pitch, pause and interjection inserts, examples, price + balance panel before spend, Generate through the guarded flow, in-place result with seek bar, job saved in Library, hub row wired. New strings in 11 languages (machine translated). Controls come from a typed seam over the web modules.
- **B (deferred, owner's word)**: Audition Board (2-3 voices, N separate jobs, `voiceAuditions.js`), Voice Recipes + palettes (web uses localStorage only: needs a storage decision), audio shelf (save with purpose/signature).
- **Deferred, blocked**: "Use for lip sync" handoff: S6 lip-sync handoff is not on `main` yet. Revisit after S6 merges.
