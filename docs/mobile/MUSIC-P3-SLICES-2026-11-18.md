## P3a contract and limits

- A fresh song read supplies the source version for review. An edit invalidates an unsubmitted quote. Confirm keeps one prefixed key per quote and shares P2's definitive rejection list. Unknown acceptance retains the original key; recovery bypasses expiry and affordability blockers only for an ambiguous attempt. Local consent/paywall rejection preserves the prior phase and cannot disclose a lost acknowledgement.
- Stem separation is charged for the attempt, even if the vocal or instrumental result is limited. The result is an archive, not a song version. Status polling starts at 1.5 seconds, backs off to 5 seconds, pauses off-active, stops on terminal/account change/dispose, and offers manual refresh after five minutes. Transient status errors never become provider failure.
- There is no stem-request list route. Request IDs and recovery attempts are memory-only on the action screen; leaving it or restarting the app loses tracking. This limitation must be included in any eventual PR description. The ZIP URL is fetched on tap and passed directly to the browser; the phone never persists, logs or downloads it.
- Crop is unpriced. Verified both `0464_music_nondestructive_crop.sql` (metadata preview) and `0472_music_canonical_wav_crop.sql` (zero-credit local render job): neither debits a balance or ledger. The server renders; the phone does not. Unsupported formats may produce a preview-only version, which is labelled explicitly. The source remains intact.
- Crop inputs use seconds, with tenths supported, and the shared server parser's finite/range/one-second limits. Duration comes from the current player's measured audio when available, otherwise from a server range error. A successful response refreshes the song and notifies the mounted library/detail screens. The library also reloads on focus.
- Per the host amendment, all new copy uses `musicActions.*` keys in `en/musicActions.ts`, matching the existing area/prefix rule. All ten non-English app catalogs contain machine translations following P2 (`7270d7835`), with unchanged slots and the required equality/expanded-copy review entries. Native review is pending; the locale-sync script is unchanged. No new packages, native changes or paid server calls.
