# Mobile roadmap (M4 onward)

**Status:** Proposed 2026-10-17, decisions agreed with the owner in chat.
**Reads with:** [GAP-ANALYSIS-2026-10-17.md](GAP-ANALYSIS-2026-10-17.md), [RESEARCH-competitors-2026-10-17.md](RESEARCH-competitors-2026-10-17.md), ADR-0106, 0108, 0109.
**Ownership:** `apps/mobile/**` and ADR-0106..0109 belong to the "Veyrnox.ai mobile app" session. This file and the two reports are the planning session's. Server pieces (S-slices) go to a separate session, one PR each.

## Decisions (owner, 2026-10-17)

1. Store-readiness first, then Cinema free viewing, then paid Cinema.
2. Editing on phone = server-rendered "quick edit" (trim, captions, stems, Film Studio runs) with on-device preview. No native multi-track timeline in v1; FFmpegKit is retired and Skia video export is beta. A spike confirms before M8.
3. Early store submission (TestFlight external review, Play internal testing), gated on the readiness items below.
4. In-app purchase is the only way to buy credits on mobile. No web link-out; revisit when the US Supreme Court rules on the Apple link-out contempt finding.
5. iOS to the store first; Android built in parallel and shipped a few weeks later.
6. Server pieces are built by a separate session, one PR each.
